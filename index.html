Troubleshooting

APK won't install

Make sure you allowed your browser to install unknown apps: Settings → Apps → Special access → Install unknown apps → your browser → Allow. Then re-open the downloaded APK file.

Samsung security warning

Samsung devices show an Auto Blocker warning for sideloaded APKs. Open Settings → Security and privacy → Auto Blocker and turn it off temporarily, install OPS Radio, then turn it back on.

Google Play Protect warning

Play Protect flags any app that isn't distributed via the Play Store. The OPS Radio APK is signed by Oxford Private Studios Ltd. Tap Install anyway to continue.

Not enough storage

The install needs around 50 MB of free space. Clear cached files in Settings → Storage and try again.

Which Android versions are supported?

Android 7.0 (Nougat) and later. The app is tested on Android 10–14.
